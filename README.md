# 🌌 Personal Portfolio Website

A modern, dark-themed personal portfolio built to showcase my journey, skills, and future projects as a Computer Science student.  
Designed with clean UI, smooth animations, and a premium aesthetic.

> This portfolio is a **living project** — it will evolve as I learn, build, and ship more real-world work.

## ✨ Features

- 🖤 Dark, minimal, premium UI
- ⚡ Smooth animations & hover effects
- 🧭 Multi-page layout (Home, About, Education, Skills, Projects, Resume, Connect)
- 📱 Fully responsive design
- 🎯 Performance-focused, no unnecessary clutter
